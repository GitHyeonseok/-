# 내 자산관리 시스템

개인 투자 전략과 전체 자산을 한 화면에서 관리하기 위한 GitHub Pages 기반
웹앱입니다.

## 주요 기능

-   총 순자산 / 투자자산 / 안전자금 / 외화RP 관리
-   QLD, QQQ, VOO, Berkshire Hathaway B, Visa, KRX 금 보유금액 관리
-   목표 포트폴리오 기준 리밸런싱 계산
-   외화RP 중 실제 투자할 금액만 선택해 리밸런싱에 반영
-   NASDAQ-100 가격, 120일 이동평균선, 200일 이동평균선 확인
-   S5TW 수동 입력 및 추세추종 매수 조건 확인
-   목표 순자산 및 월 추가 저축·투자액 관리
-   투자 원금, 배당·이자, 평가손익 및 수익률 관리
-   매매일지 기록
-   순자산 스냅샷 기록
-   월 현금흐름 관리
-   증권사/은행 앱 스크린샷 AI 자산 인식
-   JSON 백업 및 복원
-   브라우저 로컬 데이터 자동 저장

## 목표 포트폴리오

  자산                     목표 비중
  ---------------------- -----------
  QLD                            30%
  QQQ                            20%
  VOO                            20%
  Berkshire Hathaway B           15%
  Visa                            5%
  KRX 금                         10%

외화RP는 고정 목표 비중에 포함하지 않습니다. 대기자금 또는 방어자금으로
관리하고, 리밸런싱 시 실제로 투입할 금액만 별도로 입력합니다.

## 추세추종 조건

공격적 매수 조건은 다음 흐름을 기준으로 판단합니다.

1.  NASDAQ-100이 120일 이동평균선과 200일 이동평균선 위에 있어야 합니다.
2.  S5TW가 30 이하로 진입한 기록이 있어야 합니다.
3.  이후 S5TW가 다시 30을 상향 돌파하면 매수 조건 충족으로 표시합니다.
4.  NASDAQ-100이 120일선 또는 200일선 아래로 내려가면 `RISK-OFF`로
    표시합니다.

S5TW 값은 사용자가 직접 입력합니다. 시장 가격·이동평균선·환율 데이터는
`data.json`에서 불러옵니다.

## 데이터 저장

개인 자산 데이터는 GitHub 저장소에 저장하지 않고 현재 브라우저의
`localStorage`에 저장됩니다.

현재 저장 키는 기존 데이터와의 호환성을 위해 `wealthManagerDataV3`를
계속 사용합니다. 업데이트 과정에서 저장 키를 임의로 변경하지 않는 것을
원칙으로 합니다.

휴대폰 데이터 이전 과정에서 브라우저 데이터가 함께 이전될 수 있지만 이를
보장할 수는 없습니다. 휴대폰 교체, 브라우저 초기화, 사이트 데이터 삭제
또는 대규모 코드 변경 전에는 JSON 백업파일을 별도로 보관하는 것을
권장합니다.

## 백업 / 복원

사이트의 **백업 / 복원** 메뉴에서 JSON 백업파일을 저장할 수 있습니다.

복원이 필요하면 백업파일 불러오기를 선택하고 이전에 저장한 JSON 파일을
불러옵니다.

중요한 변경 전에는 다음 순서를 권장합니다.

`JSON 백업 → index.html 업데이트 → 기존 데이터 확인 → 정상 작동 확인`

## 스크린샷 AI 분석

증권사 또는 은행 앱의 자산 화면을 사이트에서 직접 선택하면 별도의 분석
서버를 통해 자산 항목과 평가금액을 인식할 수 있습니다.

인식된 값은 자동 확정하지 않습니다. 화면에서 종목 분류와 금액을
확인·수정한 뒤 **확인한 금액을 내 자산에 반영** 버튼을 눌러 적용합니다.

스크린샷 분석에는 별도로 설정한 Cloudflare Worker 주소가 필요합니다. API
키를 `index.html`에 직접 넣으면 안 됩니다.

## 파일 구성

``` text
/
├─ index.html       # 자산관리 웹앱
├─ data.json        # 시장 데이터
├─ manifest.json    # PWA 설정
├─ update_data.py   # 시장 데이터 업데이트
├─ README.md
└─ .github/
   └─ workflows/    # GitHub Actions 자동 업데이트
```

## 실행

GitHub Pages에 배포한 경우 별도의 설치 프로그램 없이 웹에서 실행할 수
있습니다.

PWA 설치가 지원되는 환경에서는 홈 화면에 추가하여 일반 앱처럼 사용할 수
있습니다.

## 주의사항

이 프로젝트는 개인 자산 기록 및 투자전략 관리 도구입니다. 실제 주문을
자동으로 실행하지 않으며, 화면에 표시되는 리밸런싱 및 전략 신호는
사용자가 입력한 데이터와 설정된 규칙을 기준으로 계산됩니다.

`index.html`을 새 버전으로 교체할 때는 기존 데이터 호환성을 먼저
확인하고, 업데이트 전에 JSON 백업을 만들어 두는 것이 안전합니다.
